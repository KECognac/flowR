# Basin for a USGS gauge: USGS flow and the NLDI basin for the site

Basin for a USGS gauge: USGS flow and the NLDI basin for the site

## Usage

``` r
wsva_basin_usgs(
  site_no,
  start = wsva_default_period()$start,
  end = wsva_default_period()$end
)
```

## Arguments

- site_no:

  USGS site number.

- start, end:

  Flow period.

## Value

A `wsva_basin`.
