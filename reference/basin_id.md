# Identifier of a basin polygon (`id`, else `site_no`)

Identifier of a basin polygon (`id`, else `site_no`)

## Usage

``` r
basin_id(basin)
```

## Arguments

- basin:

  sf polygon from
  [`get_gauge_basin()`](https://kecognac.github.io/flowR/reference/get_gauge_basin.md),
  [`delineate_basin()`](https://kecognac.github.io/flowR/reference/delineate_basin.md)
  or a user.
