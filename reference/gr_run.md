# Run a CemaNeige-GR model and return simulated flow (mm/day)

Run a CemaNeige-GR model and return simulated flow (mm/day)

## Usage

``` r
gr_run(setup, par)
```

## Arguments

- setup:

  Output of
  [`gr_setup()`](https://kecognac.github.io/flowR/reference/gr_setup.md).

- par:

  Named list or vector with the model's X parameters, C1, C2.
