# Skill summary of a `wsva_fit`

Skill summary of a `wsva_fit`

## Usage

``` r
# S3 method for class 'wsva_fit'
summary(object, ...)
```

## Arguments

- object:

  A `wsva_fit`.

- ...:

  Unused.

## Value

A `summary.wsva_fit`: list(skill = blocked-CV medians per model (plus
model mean and day-of-year climatology), contrast = climate-contrast
medians per model (if run), checks).
