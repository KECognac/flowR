# Error metrics: root mean square error, mean absolute error, sum of squared errors

Error metrics: root mean square error, mean absolute error, sum of
squared errors

## Usage

``` r
rmse(obs, sim)

mae(obs, sim)

sse(obs, sim)
```

## Arguments

- obs, sim:

  Observed and simulated values; pairs with an NA are dropped.

## Value

A number (NA if no complete pairs).
