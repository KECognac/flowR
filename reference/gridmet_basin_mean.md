# Area-weighted basin-mean daily GridMET forcing

Area-weighted basin-mean daily GridMET forcing

## Usage

``` r
gridmet_basin_mean(gm)
```

## Arguments

- gm:

  Output of
  [`get_gridmet_cells()`](https://kecognac.github.io/flowR/reference/get_gridmet_cells.md).

## Value

Tibble: date plus one column per variable, and tmean_c.
