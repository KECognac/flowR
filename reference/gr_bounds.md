# Default calibration bounds for CemaNeige-GR4J/5J/6J

Ranges follow common airGR practice; X2 \< 0 is a groundwater loss. X5
is dimensionless in GR5J (0-1) and GR6J (-2 to 2, airGR's search range);
X6 is the GR6J exponential-store coefficient (mm).

## Usage

``` r
gr_bounds(model = "GR4J")
```

## Arguments

- model:

  "GR4J", "GR5J" or "GR6J".
